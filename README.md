## A simple core mod for Cave Horror Project. Will add only a few features.

Features made so far:
- Icons for quest rewards
- Made fortune work on Ancient Debris
- Netherite Scrap now has a bit cheaper recipe
- World-specific config for From the Fog mod
- Several new item drops for Cave Dweller and The Man From The Fog, and several new items crafted from these item drops
- Advancements for defeating each main horror mob (Cave Dweller, The Man From The Fog, The Knocker)
